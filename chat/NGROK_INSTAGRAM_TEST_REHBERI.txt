`ALPHA ACADEMY - NGROK VE INSTAGRAM TEST REHBERI
================================================



s'fre Alpha.123!

Bu rehber, Django uygulamasini yerel bilgisayarda calistirip ngrok ile Instagram/Meta uzerinden test etmek icindir.

ONEMLI GUVENLIK NOTU
--------------------
Bu projedeki .env degerleri sohbet ve editor ekraninda gorundu. Asagidaki bilgileri Meta, Google ve ngrok panellerinden yenilemeden test yapma:

- Instagram App Secret
- Instagram Access Token
- Gemini API Key
- ngrok Auth Token
- Django SECRET_KEY

Asagidaki komutlarda gercek secret veya token yazma. Sadece kendi .env dosyana ekle.


1. PROJE KLASORUNE GIR
----------------------
PowerShell ac ve su komutlari calistir:

cd C:\Users\USER\Desktop\chatrag\chat
..\my_env\Scripts\Activate.ps1

Virtual environment aktif oldugunda komut satirinin basinda genellikle (my_env) gorunur.


2. .ENV DOSYASINI HAZIRLA
--------------------------
C:\Users\USER\Desktop\chatrag\chat\.env dosyasini ac ve asagidaki alanlari kendi yenilenmis degerlerinle doldur:

DEBUG=False
SECRET_KEY=yeni-django-secret-key
ALLOWED_HOSTS=localhost,127.0.0.1

INSTAGRAM_APP_ID=Meta-panelindeki-app-id
INSTAGRAM_APP_SECRET=Meta-panelindeki-yeni-app-secret
INSTAGRAM_REDIRECT_URI=https://NGROK_ADRESIN.ngrok-free.dev/auth/oauth/callback/
INSTAGRAM_ACCESS_TOKEN=yenilenmis-access-token
INSTAGRAM_WEBHOOK_VERIFY_TOKEN=kendin-belirledigin-webhook-token

GEMINI_API_KEY=yenilenmis-gemini-api-key
GEMINI_MODELS=gemini-2.5-flash-lite,gemini-2.5-flash
NGROK_AUTH_TOKEN=yenilenmis-ngrok-token

NGROK_ADRESIN yerine ngrok basladiktan sonra sana verilen adresi yazacaksin.
Ornek:
https://abc123.ngrok-free.dev/auth/oauth/callback/

Dikkat:
- URL sonunda / bulunmali.
- Meta panelindeki callback URL ile .env icindeki URL birebir ayni olmali.
- Her ngrok baslatmada adres degisirse .env ve Meta ayarlarini tekrar guncelle.


3. VERITABANI MIGRATIONLARINI UYGULA
-------------------------------------
Proje klasorunde:

python manage.py migrate
python manage.py check

Beklenen sonuc:
- check komutu hata vermemeli.
- MessageJob modeli icin migration uygulanmis olmali.


4. DJANGO SUNUCUSUNU BASLAT
----------------------------
Ilk PowerShell penceresinde:

python manage.py runserver 127.0.0.1:8000

Bu pencereyi kapatma.

Tarayicida su adresi kontrol et:

http://127.0.0.1:8000/

Uygulamanin ana sayfasi aciliyorsa Django yerel olarak calisiyor demektir.


5. NGROK'U BASLAT
-----------------
Ikinci bir PowerShell penceresi ac.

cd C:\Users\USER\Desktop\chatrag
ngrok config add-authtoken YENI_NGROK_AUTH_TOKEN
ngrok http 127.0.0.1:8000

Not:
- `ngrok http https://localhost:8000` kullanma; Django runserver HTTPS degil HTTP dinliyor.
- `ngrok tcp 8000` kullanma; Instagram/Meta icin HTTP tunnel gereklidir.
- Yerel tarayicida `http://127.0.0.1:8000/`, Instagram testinde ise ngrok'un verdigi `https://...ngrok-free.dev/` adresini kullan.

Eger auth token daha once ayarlandiysa sadece su komut yeterlidir:

ngrok http 8000

Ngrok ekraninda su sekilde bir Forwarding adresi gorursun:

https://abc123.ngrok-free.dev -> http://localhost:8000

Bu HTTPS adresini kopyala.

Tarayicida kontrol et:

https://abc123.ngrok-free.dev/

Sayfa aciliyorsa ngrok ve Django baglantisi calisiyor.


6. .ENV'DEKI CALLBACK ADRESINI GUNCELLE

https://abc123.ngrok-free.dev/auth/oauth/callback/

14. VERITABANINI KONTROL ET
----------------------------
Django shell ile kuyruk durumlarini kontrol edebilirsin:

python manage.py shell

Shell icinde:

from main.models import InstagramMessage, MessageJob
InstagramMessage.objects.order_by('-timestamp')[:5]
MessageJob.objects.values('id', 'status', 'attempts', 'last_error')

Durumlar:
- pending: Islenmeyi bekliyor
- processing: Worker isliyor
- completed: Basarili
- failed: Uc denemeden sonra basarisiz

Shell'den cikmak icin:

exit()


15. SIK KARSILASILAN HATALAR
-----------------------------

400 - Gecersiz OAuth state degeri
- Login akisini callback URL'sinden elle baslatmissin.
- /auth/oauth/login/ adresinden yeniden baslat.
- Tarayici cookie/session bilgilerini silip tekrar dene.

403 - Gecersiz webhook imzasi
- Elle gonderilen POST isteginde Meta imzasi yoktur.
- Meta'dan gelen gercek webhook istegiyle test et.

403 - Webhook dogrulama basarisiz
- Meta Verify Token ile .env INSTAGRAM_WEBHOOK_VERIFY_TOKEN farkli.
- Verify Token'i karakter karakter ayni yap.

Redirect URI mismatch
- Meta callback adresi ile INSTAGRAM_REDIRECT_URI ayni degil.
- Ngrok adresi degismis olabilir.

Instagram token alinamadi
- App Secret eski veya yanlis olabilir.
- Test hesabi uygulama rolunde olmayabilir.
- Izinler hesap turuyle uyusmuyor olabilir.

Mesaj geliyor ama cevap gitmiyor
- Webhook mesaji pending olarak kaydetmistir.
- process_message_queue komutunu calistir.
- Gemini loglarini ve Instagram API hata loglarini kontrol et.
- INSTAGRAM_ACCESS_TOKEN yenilenmis ve dogru mu kontrol et.

Gemini cevap vermiyor
- GEMINI_API_KEY yenilenmis mi kontrol et.
- GEMINI_MODELS icindeki model isimleri API hesabinda destekleniyor mu kontrol et.
- Queue job pending veya failed durumuna bak.

Ngrok ERR_NGROK_3200 veya baglanti yok
- Django runserver hala calisiyor mu kontrol et.
- ngrok'un 8000 portunu yonlendirdigini kontrol et.
- Windows Firewall veya ag baglantisini kontrol et.
